# CloudDesk Technologies — Company Profile & Business Environment

## 1. Overview
* **Company Name**: CloudDesk Technologies
* **Industry**: Enterprise Software-as-a-Service (SaaS)
* **Employees**: 600 full-time employees and contract engineers
* **Enterprise Customers**: ~800 global enterprise organizations
* **Primary Role**: GRC Analyst — Security Compliance

## 2. Technology Environment & Stack
* **Cloud Infrastructure**: Amazon Web Services (AWS us-east-1, us-west-2 multi-region deployment)
* **Container Orchestration**: Kubernetes (Amazon EKS) clusters running microservices
* **Databases & Caching**: PostgreSQL RDS Multi-AZ, Redis Cache Cluster
* **Application Layer**: RESTful APIs, Web applications, Mobile apps
* **CI/CD Pipeline**: GitHub Enterprise, GitHub Actions automated deployment pipelines
* **Identity Management**: Auth0 Cloud IAM, AWS IAM Identity Center

## 3. Core Business Problem
Enterprise customers routinely request security assurance prior to contract renewal or expansion ("Are you SOC 2 compliant?", "Show evidence of quarterly access reviews"). CloudDesk maintained robust technical controls, but compliance operations were fragmented across email threads, shared drives, ticket queues, and AWS console exports. Management mandated establishing a centralized, repeatable GRC operating framework.
