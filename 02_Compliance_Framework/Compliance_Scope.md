# CloudDesk Technologies — Compliance Scope Document

## 1. Executive Summary
This document defines the official compliance boundary for CloudDesk Technologies' Security Compliance & GRC Program, encompassing all personnel, cloud technologies, infrastructure components, and operational processes associated with delivering the Enterprise SaaS platform.

## 2. In-Scope Environments & Technology Architecture
* **Cloud Infrastructure**: Amazon Web Services (AWS us-east-1, us-west-2 multi-region deployment).
* **Container Orchestration**: Production Kubernetes (EKS) clusters hosting microservices.
* **Databases & Caching**: PostgreSQL (RDS Multi-AZ), Redis Cluster.
* **Application Services**: REST APIs, Front-end Web Application, Mobile Application APIs.
* **CI/CD & Source Code**: GitHub Enterprise, GitHub Actions automated deployment pipelines.
* **Identity & Access**: Auth0 Cloud IAM, AWS IAM Identity Center, Okta Enterprise SSO.

## 3. In-Scope Personnel
* **Total Employees & Contractors**: ~600 FTEs across Software Engineering, DevOps, Cloud Infrastructure, Security Operations, Product Management, Customer Support, Human Resources, Finance, Legal, and Executive Leadership.

## 4. In-Scope Operational Processes
1. Access Governance & Joiner-Mover-Leaver (JML)
2. Privileged Access Management (PAM) & Quarterly Reviews
3. Vulnerability Management & Patching
4. Change Management & Secure SDLC
5. Incident Response & Threat Monitoring
6. Vendor Risk Management & Third-Party Assessments
7. Business Continuity & Disaster Recovery (BCP/DR)
8. Security Awareness & Training
